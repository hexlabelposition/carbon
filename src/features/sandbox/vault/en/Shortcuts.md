# Shortcuts

On a Mac, Cmd takes the place of Ctrl.

| Keys         | What they do                         |
| ------------ | ------------------------------------ |
| Ctrl+P       | The command palette: everything      |
| Ctrl+O       | Open a note by its name, or make one |
| Ctrl+Shift+F | Search the text of every note        |
| Ctrl+E       | Reading mode on and off              |
| Ctrl+B       | The left panel                       |
| Ctrl+Shift+B | The right panel                      |
| Ctrl+W       | Close the tab                        |
| Ctrl+,       | Settings                             |
| Ctrl+= / -   | Zoom the interface in and out        |

Any of them can be changed in the Shortcuts group of the settings.
