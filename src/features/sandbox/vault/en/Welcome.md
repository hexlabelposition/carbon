# Welcome

This is the sandbox: a vault to try Carbon in. Change, rename or delete anything here. It is made afresh each time you open it from the start screen, so nothing you do here is kept.

A vault is just a folder of Markdown files. Carbon reads and writes them as they are: you can open the same folder in any other editor.

## Where to go next

- [[Writing]]: headings, lists, tasks, quotes, callouts, code and tables
- [[Linking notes]]: links between notes, to headings and to blocks
- [[Tags]]: sorting notes without folders
- [[Embeds and images]]: one note inside another, and pictures
- [[Shortcuts]]: the keys worth knowing
- [[Reading list]] and [[Weekly review]], in the `Ideas` folder: notes as you might keep them

> [!tip] Three views of a note
> The button above the note switches between **live preview**, where the Markdown hides as you write, **source**, where it all shows, and **reading**. Ctrl+E goes in and out of reading.

When you are ready, go back to the start screen and open a folder of your own, or create a new vault.
