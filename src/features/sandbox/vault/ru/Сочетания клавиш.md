# Сочетания клавиш

На Mac вместо Ctrl — Cmd.

| Клавиши      | Что делают                      |
| ------------ | ------------------------------- |
| Ctrl+P       | Палитра команд: всё, что есть   |
| Ctrl+O       | Открыть заметку по имени        |
| Ctrl+N       | Новая заметка                   |
| Ctrl+Shift+F | Поиск по тексту всех заметок    |
| Ctrl+E       | Включить и выключить чтение     |
| Ctrl+B       | Левая панель                    |
| Ctrl+Shift+B | Правая панель                   |
| Ctrl+W       | Закрыть вкладку                 |
| Ctrl+,       | Настройки                       |
| Ctrl+= / -   | Увеличить и уменьшить интерфейс |

Любое из них можно поменять в разделе «Сочетания клавиш» настроек.
