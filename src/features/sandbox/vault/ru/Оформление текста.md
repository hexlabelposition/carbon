# Оформление текста

Carbon пишет обычный Markdown. В динамическом режиме разметка прячется, как только курсор уходит с неё: поставьте курсор на строку, чтобы увидеть, из чего она сделана.

## Текст

**Жирный**, _курсив_, ~~зачёркнутый~~, `код в строке` и [ссылка в интернет](https://commonmark.org).

Кнопка с клавиатурой над заметкой открывает панель форматирования: выделите текст и нажмите кнопку, чтобы его оформить.

## Списки и задачи

- Пункт списка
- Ещё один
  - Tab вкладывает пункт, Shift+Tab возвращает его
- Enter на пустом пункте завершает список

1. Нумерованные списки
2. считают сами

- [x] Прочитать приветствие
- [ ] Нажать на флажок, чтобы отметить задачу
- [ ] Написать свою заметку

## Цитаты и выноски

> Цитата — это строка, которая начинается с `>`.

> [!note]
> Выноска — это цитата с типом в скобках в первой строке.

> [!warning] Свой заголовок
> У неё может быть свой заголовок и любой текст внутри.
