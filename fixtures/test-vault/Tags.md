# Tags

Simple tags: #carbon #testing

Nested tags: #project/carbon #project/carbon/editor

A tag at the end of a sentence #last.

Back to [[Links]].

## Not tags

- A heading mark is not a tag, see the heading above
- An address with a fragment: https://example.com/page#section
- A number: issue #42
- In code: `#not-a-tag`

```
#also-not-a-tag
```
